Le HTML, c'est comme le vélo : au début on tombe, puis on écrit des pages entières sans y penser.
Voici le strict minimum pour publier sa première page personnelle.

## Les balises de base

### Les titres

Un document commence par un titre principal. **Un seul titre de niveau 1 par page**, c'est la
règle d'or.

```html
<h1>Mon premier titre</h1>
<p>Bonjour le web !</p>
```

### Les paragraphes et l'emphase

On entoure le texte de balises `<p>`, et on peut le mettre en **gras** ou en *italique*.

## Faire une liste

Une liste à puces :

- un fond d'écran qui brille ;
- un compteur de visites ;
- un livre d'or.

Une liste numérotée :

1. écrire la page dans Notepad ;
2. l'envoyer par FTP ;
3. rafraîchir le navigateur toutes les deux minutes.

## Les erreurs à éviter

Certaines balises sont à bannir de nos jours :

- `<marquee>`, qui fait défiler le texte de force ;
- `<blink>`, qui fatigue les yeux ;
- les tableaux utilisés pour la mise en page.

> Une page lisible vaut mieux qu'une page qui clignote. Enfin, c'était mon avis en 2005.

## Et ensuite ?

Apprends les feuilles de style CSS pour changer les couleurs sans tout réécrire. Le site
[W3C](https://www.w3.org/) (lien externe) reste la référence pour les normes.
